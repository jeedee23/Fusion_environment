# Fusion_environment

`customizeEnvironment` is the Fusion theme-customization utility for editing
colors in `PhotoBooth.xml`. It can also be launched from this repository:

```sh
python3 customize_environment.py
```

Open the `PhotoBooth.xml` file used by Fusion, then double-click a recognized
hexadecimal color value to change it. Save writes the updated XML back to the
opened file.
